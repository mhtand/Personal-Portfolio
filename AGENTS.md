# Project guidelines

This personal portfolio is a learning project built with Astro and TypeScript.

- Build the website incrementally, in small steps requested by the user. Do not generate the entire portfolio at once.
- Help the user understand the code. Explain unfamiliar concepts and the purpose of meaningful changes in plain language.
- Keep the project lightweight. Prefer Astro's built-in features, semantic HTML, plain CSS, and TypeScript.
- Avoid unnecessary dependencies, additional frameworks, libraries, abstractions, and overengineering.
- Do not make large changes or expand the scope unless the user asks.
- Follow existing project conventions and keep code readable for a learner.
- Verify changes with checks appropriate to their scope and explain the results.
- During initial setup, leave the minimal starter page intact. Portfolio content and design will be built later.
